# 03 - 配置文件设计

## 1. 环境变量模板 (.env.example)

```env
# ============================================
# 主机器人配置
# ============================================
MASTER_BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
ADMIN_USER_IDS=123456789,987654321

# ============================================
# 数据库配置
# ============================================
# SQLite（默认，开发环境）
DATABASE_URL=sqlite+aiosqlite:///data/bot.db

# PostgreSQL（生产环境，取消注释切换）
# DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/bibot

# ============================================
# 安全配置
# ============================================
# Fernet 加密密钥（用于加密存储 Bot Token）
# 生成方式: python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
TOKEN_ENCRYPTION_KEY=your-fernet-key-here

# ============================================
# 广告默认配置
# ============================================
DEFAULT_AD_TEXT=Powered by @YourPlatformBot
DEFAULT_AD_URL=https://t.me/YourPlatformBot

# ============================================
# 广播配置
# ============================================
# 每秒最大发送消息数（Telegram API 限制约 30条/秒，建议设 20）
BROADCAST_RATE_LIMIT=20

# ============================================
# 子Bot配置
# ============================================
# 每个用户最多注册的Bot数量
MAX_BOTS_PER_USER=3

# 消息映射保留天数（超过自动清理）
MESSAGE_MAP_RETENTION_DAYS=30

# ============================================
# 日志配置
# ============================================
LOG_LEVEL=INFO
LOG_FILE=logs/bot.log
```

## 2. 配置类定义 (config.py)

```python
from pydantic_settings import BaseSettings
from pydantic import field_validator


class Settings(BaseSettings):
    """应用全局配置，从 .env 文件和环境变量加载"""

    # --- 主机器人 ---
    MASTER_BOT_TOKEN: str
    ADMIN_USER_IDS: list[int]

    # --- 数据库 ---
    DATABASE_URL: str = "sqlite+aiosqlite:///data/bot.db"

    # --- 安全 ---
    TOKEN_ENCRYPTION_KEY: str

    # --- 广告 ---
    DEFAULT_AD_TEXT: str = "Powered by @YourPlatformBot"
    DEFAULT_AD_URL: str = ""

    # --- 广播 ---
    BROADCAST_RATE_LIMIT: int = 20

    # --- 子Bot ---
    MAX_BOTS_PER_USER: int = 3
    MESSAGE_MAP_RETENTION_DAYS: int = 30

    # --- 日志 ---
    LOG_LEVEL: str = "INFO"
    LOG_FILE: str = "logs/bot.log"

    @field_validator("ADMIN_USER_IDS", mode="before")
    @classmethod
    def parse_admin_ids(cls, v):
        if isinstance(v, str):
            return [int(x.strip()) for x in v.split(",") if x.strip()]
        return v

    model_config = {
        "env_file": ".env",
        "env_file_encoding": "utf-8",
    }
```

## 3. 配置使用方式

```python
# 全局单例
from app.config import Settings

settings = Settings()

# 使用示例
bot = Bot(token=settings.MASTER_BOT_TOKEN)
is_admin = user_id in settings.ADMIN_USER_IDS
```

## 4. 配置项说明

| 配置项 | 必填 | 默认值 | 说明 |
|--------|------|--------|------|
| `MASTER_BOT_TOKEN` | 是 | - | 主机器人的 Bot Token |
| `ADMIN_USER_IDS` | 是 | - | 平台管理员的 Telegram user_id，逗号分隔 |
| `DATABASE_URL` | 否 | `sqlite+aiosqlite:///data/bot.db` | 数据库连接字符串 |
| `TOKEN_ENCRYPTION_KEY` | 是 | - | Fernet 密钥，用于加密子Bot Token |
| `DEFAULT_AD_TEXT` | 否 | `Powered by @YourPlatformBot` | 默认广告文本 |
| `DEFAULT_AD_URL` | 否 | 空 | 默认广告链接 |
| `BROADCAST_RATE_LIMIT` | 否 | `20` | 广播每秒发送上限 |
| `MAX_BOTS_PER_USER` | 否 | `3` | 每用户最多注册Bot数 |
| `MESSAGE_MAP_RETENTION_DAYS` | 否 | `30` | 消息映射保留天数 |
| `LOG_LEVEL` | 否 | `INFO` | 日志级别 |
| `LOG_FILE` | 否 | `logs/bot.log` | 日志文件路径 |
