# Telegram 双向机器人托管平台 - 总览

## 1. 项目定位

构建一个 Telegram 双向机器人托管平台。用户通过主机器人（Master Bot）提交自己的 Bot Token，
系统自动将其 Bot 变为双向消息转发机器人。平台支持广告注入和广播功能作为变现手段。

## 2. 角色定义

| 角色 | 身份 | 权限范围 |
|------|------|----------|
| **平台管理员** | 运营方，ADMIN_USER_IDS 中的用户 | 管理所有子Bot、广告系统、全局统计、强制停止任意Bot |
| **Bot 主人** | 通过主Bot提交Token的普通用户 | 管理自己的子Bot、广播、封禁自己Bot的用户 |
| **终端用户** | 给子Bot发消息的任意Telegram用户 | 发送消息、接收回复 |

## 3. 技术栈

| 组件 | 选型 | 版本要求 |
|------|------|----------|
| 语言 | Python | >= 3.11 |
| Bot框架 | aiogram | >= 3.20 |
| 数据库 | SQLite（初期）/ PostgreSQL（扩展） | - |
| ORM | SQLAlchemy 2.0 + aiosqlite | >= 2.0 |
| 数据库迁移 | Alembic | >= 1.14 |
| 配置管理 | pydantic-settings | >= 2.0 |
| Token加密 | cryptography (Fernet) | >= 44.0 |
| 缓存（可选） | Redis | >= 5.0 |

## 5. 核心流程总览

```
┌──────────┐                    ┌──────────┐                    ┌──────────┐
│ 终端用户  │ ── 发送消息 ──→    │  子Bot   │ ── 转发+用户头 ──→ │ Bot主人  │
│          │ ←─ 回复+广告尾 ──  │          │ ←─ 回复消息 ─────  │          │
└──────────┘                    └──────────┘                    └──────────┘
                                     │
                                     │ 广告注入（仅回复方向）
                                     │
                                ┌──────────┐
                                │ 广告系统  │
                                └──────────┘
```
