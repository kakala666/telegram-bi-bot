# 02 - 数据库设计

## 1. 总览

共 5 张表，使用 SQLAlchemy 2.0 ORM 定义。

```
┌───────────┐       ┌───────────┐       ┌──────────────┐
│  sub_bots │──1:N──│ bot_users │       │ message_maps │
│           │       │           │       │              │
│ id (PK)   │       │ id (PK)   │       │ id (PK)      │
│ bot_token │       │ sub_bot_id│──FK──→│ sub_bot_id   │
│ owner_id  │       │ user_id   │       │ user_id      │
│ ...       │       │ ...       │       │ ...          │
└───────────┘       └───────────┘       └──────────────┘
      │
      │ 1:N
      ▼
┌──────────────┐    ┌───────────────┐
│ ad_configs   │    │broadcast_tasks│
│              │    │               │
│ id (PK)      │    │ id (PK)       │
│ target_bot_id│    │ sub_bot_id    │
│ ...          │    │ ...           │
└──────────────┘    └───────────────┘
```

---

## 2. sub_bots 表（子机器人）

存储所有注册的子Bot信息。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | INTEGER | PK, AUTO_INCREMENT | 主键 |
| `bot_token_encrypted` | TEXT | NOT NULL, UNIQUE | Fernet 加密后的 Bot Token |
| `bot_id` | BIGINT | NOT NULL, UNIQUE | Telegram Bot 的数字 ID（`bot.get_me().id`） |
| `bot_username` | VARCHAR(64) | NOT NULL | Bot 用户名（不含@） |
| `owner_id` | BIGINT | NOT NULL | Bot 主人的 Telegram user_id |
| `owner_username` | VARCHAR(64) | NULLABLE | Bot 主人的用户名（可选，用于显示） |
| `status` | VARCHAR(16) | NOT NULL, DEFAULT 'active' | 状态：`active` / `stopped` / `error` / `token_invalid` |
| `welcome_message` | TEXT | NULLABLE | 终端用户 /start 时的自定义欢迎语 |
| `user_count` | INTEGER | NOT NULL, DEFAULT 0 | 终端用户总数（冗余计数，定期同步） |
| `message_count` | INTEGER | NOT NULL, DEFAULT 0 | 总消息数（冗余计数） |
| `created_at` | DATETIME | NOT NULL, DEFAULT NOW | 注册时间 |
| `updated_at` | DATETIME | NOT NULL, DEFAULT NOW, ON UPDATE NOW | 最后更新时间 |

**索引：**
- `idx_sub_bots_owner_id` ON (`owner_id`) — 按主人查询其所有Bot
- `idx_sub_bots_bot_id` ON (`bot_id`) UNIQUE — 按 Telegram bot_id 快速查找
- `idx_sub_bots_status` ON (`status`) — 启动时恢复 active Bot

---

## 3. bot_users 表（终端用户）

记录每个子Bot的终端用户信息。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | INTEGER | PK, AUTO_INCREMENT | 主键 |
| `sub_bot_id` | INTEGER | NOT NULL, FK → sub_bots.id | 所属子Bot |
| `user_id` | BIGINT | NOT NULL | 终端用户 Telegram user_id |
| `username` | VARCHAR(64) | NULLABLE | 用户名（可能为空） |
| `first_name` | VARCHAR(128) | NULLABLE | 名 |
| `last_name` | VARCHAR(128) | NULLABLE | 姓 |
| `display_name` | VARCHAR(256) | NOT NULL | 显示名（first_name + last_name 拼接） |
| `is_blocked` | BOOLEAN | NOT NULL, DEFAULT FALSE | 是否被Bot主人封禁 |
| `is_banned_by_telegram` | BOOLEAN | NOT NULL, DEFAULT FALSE | 用户是否已屏蔽Bot（发送失败时标记） |
| `first_seen` | DATETIME | NOT NULL, DEFAULT NOW | 首次使用时间 |
| `last_active` | DATETIME | NOT NULL, DEFAULT NOW | 最后活跃时间 |

**索引：**
- `idx_bot_users_sub_bot_user` ON (`sub_bot_id`, `user_id`) UNIQUE — 同一Bot下用户唯一
- `idx_bot_users_sub_bot_blocked` ON (`sub_bot_id`, `is_blocked`) — 查询未封禁用户（广播用）

---

## 4. message_maps 表（消息映射）

记录转发消息的 ID 对应关系，用于回复路由。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | INTEGER | PK, AUTO_INCREMENT | 主键 |
| `sub_bot_id` | INTEGER | NOT NULL, FK → sub_bots.id | 所属子Bot |
| `user_id` | BIGINT | NOT NULL | 终端用户 Telegram user_id |
| `user_msg_id` | INTEGER | NOT NULL | 用户在子Bot聊天中发送的消息ID |
| `forwarded_msg_id` | INTEGER | NOT NULL | 转发到Bot主人聊天中的消息ID |
| `direction` | VARCHAR(8) | NOT NULL, DEFAULT 'in' | `in`=用户→主人, `out`=主人→用户 |
| `created_at` | DATETIME | NOT NULL, DEFAULT NOW | 创建时间 |

**索引：**
- `idx_msg_map_forwarded` ON (`sub_bot_id`, `forwarded_msg_id`) — Bot主人回复时查找原始用户
- `idx_msg_map_created` ON (`created_at`) — 定期清理旧映射

**清理策略：** 超过 30 天的映射记录自动删除（通过定时任务或启动时清理）。

---

## 5. ad_configs 表（广告配置）

平台方管理的广告内容。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | INTEGER | PK, AUTO_INCREMENT | 主键 |
| `name` | VARCHAR(64) | NOT NULL | 广告名称（管理用，如"默认广告"） |
| `ad_text` | TEXT | NOT NULL | 广告文本内容（支持 HTML 格式） |
| `ad_url` | VARCHAR(512) | NULLABLE | 广告链接 |
| `button_text` | VARCHAR(64) | NULLABLE | 内联按钮文字（如果需要按钮式广告） |
| `button_url` | VARCHAR(512) | NULLABLE | 内联按钮链接 |
| `is_active` | BOOLEAN | NOT NULL, DEFAULT TRUE | 是否启用 |
| `target_type` | VARCHAR(16) | NOT NULL, DEFAULT 'global' | `global`=所有Bot / `specific`=指定Bot |
| `target_bot_id` | INTEGER | NULLABLE, FK → sub_bots.id | 指定Bot（target_type=specific时） |
| `priority` | INTEGER | NOT NULL, DEFAULT 0 | 优先级（数字越大越优先） |
| `impression_count` | INTEGER | NOT NULL, DEFAULT 0 | 展示次数 |
| `created_at` | DATETIME | NOT NULL, DEFAULT NOW | 创建时间 |
| `updated_at` | DATETIME | NOT NULL, DEFAULT NOW | 更新时间 |

**索引：**
- `idx_ad_active_priority` ON (`is_active`, `priority` DESC) — 查询活跃广告按优先级排序
- `idx_ad_target` ON (`target_type`, `target_bot_id`) — 按目标类型查询

---

## 6. broadcast_tasks 表（广播任务）

记录每次广播的执行状态。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | INTEGER | PK, AUTO_INCREMENT | 主键 |
| `sub_bot_id` | INTEGER | NOT NULL, FK → sub_bots.id | 发起广播的子Bot |
| `owner_id` | BIGINT | NOT NULL | 发起者 user_id |
| `content_type` | VARCHAR(16) | NOT NULL | `text` / `photo` / `video` / `document` / `audio` / `sticker` |
| `content_text` | TEXT | NULLABLE | 文本内容（text类型时） |
| `content_file_id` | VARCHAR(256) | NULLABLE | 媒体文件的 file_id（媒体类型时） |
| `content_caption` | TEXT | NULLABLE | 媒体的 caption（媒体类型时） |
| `total_count` | INTEGER | NOT NULL, DEFAULT 0 | 目标用户总数 |
| `sent_count` | INTEGER | NOT NULL, DEFAULT 0 | 已成功发送数 |
| `failed_count` | INTEGER | NOT NULL, DEFAULT 0 | 发送失败数 |
| `status` | VARCHAR(16) | NOT NULL, DEFAULT 'pending' | `pending` / `running` / `completed` / `cancelled` |
| `created_at` | DATETIME | NOT NULL, DEFAULT NOW | 创建时间 |
| `completed_at` | DATETIME | NULLABLE | 完成时间 |

**索引：**
- `idx_broadcast_sub_bot` ON (`sub_bot_id`, `status`) — 查询某Bot的广播任务
- `idx_broadcast_status` ON (`status`) — 查询运行中的任务

---

## 7. 表关系图

```
sub_bots (1) ──→ (N) bot_users
    │                    用户属于某个子Bot
    │
    ├──→ (N) message_maps
    │        消息映射属于某个子Bot
    │
    ├──→ (N) ad_configs (target_type='specific')
    │        指定Bot的专属广告
    │
    └──→ (N) broadcast_tasks
             广播任务属于某个子Bot
```

## 8. 数据量预估与清理

| 表 | 预估增长速度 | 清理策略 |
|----|-------------|----------|
| sub_bots | 低（每天几个） | 不清理 |
| bot_users | 中（每Bot每天几十个） | 不清理 |
| message_maps | 高（每条消息一条记录） | 30天自动清理 |
| ad_configs | 极低 | 不清理 |
| broadcast_tasks | 低 | 90天自动清理 |
