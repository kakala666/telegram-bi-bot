## 1. 权限体系

### 1.1 三级权限模型

```
┌─────────────────────────────────────────┐
│ Level 3: 平台管理员 (ADMIN)              │
│ ├── 管理所有子Bot（强制停止/删除）         │
│ ├── 广告系统管理（增删改查）               │
│ ├── 全局统计查看                          │
│ ├── 系统状态监控                          │
│ └── 全局广播                              │
├─────────────────────────────────────────┤
│ Level 2: Bot主人 (OWNER)                 │
│ ├── 注册/删除自己的Bot                    │
│ ├── 启停自己的Bot                         │
│ ├── 设置欢迎语                            │
│ ├── 查看自己Bot的用户列表                  │
│ ├── 封禁/解封自己Bot的用户                 │
│ └── 向自己Bot的用户广播                    │
├─────────────────────────────────────────┤
│ Level 1: 终端用户 (USER)                 │
│ ├── 给子Bot发送消息                       │
│ ├── 接收Bot主人的回复                     │
│ └── /start 查看欢迎语                     │
└─────────────────────────────────────────┘
```

### 1.2 权限判断逻辑

```python
def is_admin(user_id: int) -> bool:
    """是否是平台管理员"""
    return user_id in settings.ADMIN_USER_IDS

async def is_bot_owner(user_id: int, bot_id: int) -> bool:
    """是否是指定Bot的主人"""
    sub_bot = await bot_repo.get(bot_id)
    return sub_bot and sub_bot.owner_id == user_id

async def has_any_bot(user_id: int) -> bool:
    """是否拥有至少一个Bot"""
    bots = await bot_repo.get_by_owner(user_id)
    return len(bots) > 0
```

### 1.3 命令权限矩阵

| 命令 | 终端用户 | Bot主人（无Bot） | Bot主人（有Bot） | 平台管理员 |
|------|---------|----------------|----------------|-----------|
| `/start` | - | 显示欢迎页 | 显示欢迎页 | 显示欢迎页 |
| `/help` | - | 显示帮助 | 显示帮助 | 显示帮助 |

### 1.4 权限检查装饰器

```python
from functools import wraps

def admin_only(handler):
    """仅平台管理员可用"""
    @wraps(handler)
    async def wrapper(message: Message, **kwargs):
        if message.from_user.id not in settings.ADMIN_USER_IDS:
            await message.answer("你没有权限使用此命令")
            return
        return await handler(message, **kwargs)
    return wrapper

def owner_required(handler):
    """需要至少拥有一个Bot"""
    @wraps(handler)
    async def wrapper(message: Message, **kwargs):
        bots = await bot_repo.get_by_owner(message.from_user.id)
        if not bots:
            await message.answer(
                "你还没有注册任何Bot\n使用 /register 注册一个"
            )
            return
        kwargs["owner_bots"] = bots
        return await handler(message, **kwargs)
    return wrapper
```

## 2. Token 安全

### 2.1 加密存储

Bot Token 使用 Fernet 对称加密存储，不以明文保存在数据库中。

```python
from cryptography.fernet import Fernet

class TokenEncryptor:
    def __init__(self, key: str):
        self._fernet = Fernet(key.encode())

    def encrypt(self, token: str) -> str:
        """加密Token"""
        return self._fernet.encrypt(token.encode()).decode()

    def decrypt(self, encrypted_token: str) -> str:
        """解密Token"""
        return self._fernet.decrypt(encrypted_token.encode()).decode()
```

### 2.2 密钥管理

```
TOKEN_ENCRYPTION_KEY 生成方式:
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

存储位置: .env 文件（不入版本控制）
```

### 2.3 Token 验证流程

```
用户提交Token后的验证步骤:

1. 格式校验
   正则: ^\d{8,10}:[A-Za-z0-9_-]{35}$
   └─→ 失败: "Token格式不正确"

2. 重复检查
   遍历数据库所有 bot_token_encrypted，解密后比对
   （或存储 bot_id 后通过 bot_id 判断）
   └─→ 已存在: "该Bot已被注册"

3. API验证
   调用 Bot(token=token).get_me()
   └─→ 失败: "Token无效或Bot不存在"
   └─→ 成功: 获取 bot_id, username, first_name

4. 数量检查
   查询该用户已注册的Bot数量
   └─→ >= MAX_BOTS_PER_USER: "你最多只能注册 {N} 个Bot"

5. 全部通过 → 进入确认流程
```

### 2.4 Token 在内存中的处理

```
启动时:
├─→ 从数据库读取 encrypted_token
├─→ 解密得到明文 token
├─→ 创建 Bot(token=token) 实例
└─→ 明文 token 不额外存储，仅存在于 Bot 实例内部

运行时:
├─→ Bot 实例持有 token（aiogram内部使用）
├─→ BotRegistry 只存储 bot_id → Bot实例 的映射
└─→ 不在日志中输出 token
```

## 3. 输入校验

### 3.1 Token 输入

```python
import re

TOKEN_PATTERN = re.compile(r"^\d{8,10}:[A-Za-z0-9_-]{35}$")

def validate_token_format(token: str) -> bool:
    """校验Token格式"""
    return bool(TOKEN_PATTERN.match(token.strip()))
```

### 3.2 用户ID输入（/block命令）

```python
def validate_user_id(text: str) -> int | None:
    """校验用户ID格式"""
    text = text.strip()
    if text.isdigit() and len(text) <= 15:
        return int(text)
    return None
```

### 3.3 广告文本输入

```python
MAX_AD_TEXT_LENGTH = 200  # 广告文本最大长度

def validate_ad_text(text: str) -> tuple[bool, str]:
    """校验广告文本"""
    if not text.strip():
        return False, "广告文本不能为空"
    if len(text) > MAX_AD_TEXT_LENGTH:
        return False, f"广告文本不能超过{MAX_AD_TEXT_LENGTH}个字符"
    return True, ""
```

### 3.4 URL输入

```python
from urllib.parse import urlparse

def validate_url(url: str) -> bool:
    """校验URL格式"""
    try:
        result = urlparse(url)
        return all([result.scheme in ("http", "https"), result.netloc])
    except Exception:
        return False
```

### 3.5 欢迎语输入

MAX_WELCOME_LENGTH = 4096  # Telegram消息最大长度

## 4. 防滥用措施

### 4.1 注册限速

```python
# 每个用户每小时最多注册 3 次（包括失败的尝试）
REGISTER_RATE_LIMIT = 3
REGISTER_RATE_WINDOW = 3600  # 秒

register_attempts: dict[int, list[float]] = {}

async def check_register_rate(user_id: int) -> bool:
    now = time.time()
    attempts = register_attempts.get(user_id, [])
    # 清理过期记录
    attempts = [t for t in attempts if now - t < REGISTER_RATE_WINDOW]
    if len(attempts) >= REGISTER_RATE_LIMIT:
        return False
    attempts.append(now)
    register_attempts[user_id] = attempts
    return True
```

### 4.2 广播限制

- 同一Bot同时只能有1个广播任务
- 两次广播间隔至少5分钟
- 广播内容不做内容审核（由Bot主人自行负责）

### 4.3 消息转发限速

```
子Bot转发消息时不做额外限速（依赖Telegram自身的限速机制）。
如果收到 TelegramRetryAfter，等待指定时间后重试。
```

## 5. 数据安全

### 5.1 敏感数据处理

| 数据 | 存储方式 | 日志输出 |
|------|----------|----------|
| Bot Token | Fernet 加密 | 禁止输出 |
| 用户消息内容 | 不存储（仅转发） | 禁止输出 |
| 用户ID | 明文存储 | 可输出 |
| 用户名 | 明文存储 | 可输出 |
| 加密密钥 | .env 文件 | 禁止输出 |

### 5.2 日志安全

```python
import logging

class SensitiveFilter(logging.Filter):
    """过滤日志中的敏感信息"""
    def filter(self, record):
        if hasattr(record, 'msg') and isinstance(record.msg, str):
            # 替换可能的Token
            record.msg = re.sub(
                r'\d{8,10}:[A-Za-z0-9_-]{35}',
                '[REDACTED_TOKEN]',
                record.msg
            )
        return True
```
