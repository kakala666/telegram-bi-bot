# 10 - 模块接口定义

## 1. 调用规则总览

### 1.1 分层依赖方向（严格单向）

```
Handler 层 ──→ Service 层 ──→ Repository 层 ──→ Database Engine
     │              │
     │              └──→ Service 层（Service之间可互相调用）
     │
     └──→ BotRegistry（仅 Master Bot Handler 调用）
```

### 1.2 禁止的调用

| 禁止方向 | 说明 |
|----------|------|
| Handler → Repository | Handler 不能直接操作数据库，必须经过 Service |
| Repository → Service | Repository 不能反向调用 Service |
| Service → Handler | Service 不能调用 Handler |
| Sub Bot Handler → BotRegistry | 子Bot Handler 不管理Bot生命周期 |
| Repository → Repository | Repository 之间不互相调用 |

### 1.3 允许的调用

| 调用方 | 被调用方 | 说明 |
|--------|----------|------|
| Master Handler | Service | 所有业务操作 |
| Master Handler | BotRegistry | 启停子Bot |
| Sub Bot Handler | ForwarderService | 消息转发 |
| ForwarderService | AdInjectorService | 回复时注入广告 |
| ForwarderService | UserRepo, MessageMapRepo, BotRepo | 数据读写 |
| BroadcastService | UserRepo, BroadcastRepo, BotRegistry | 广播执行 |
| AdInjectorService | AdRepo | 读取广告配置 |
| TokenValidatorService | BotRepo | 检查重复 |
| BotRegistry | BotRepo | 恢复时读取活跃Bot |
| Launcher | 所有模块 | 初始化和组装 |

### 1.4 依赖关系图

```
┌─────────────────────────────────────────────────────────────────┐
│ Launcher (组装所有依赖)                                          │
│                                                                  │
│  创建顺序:                                                       │
│  1. Settings (config)                                            │
│  2. DatabaseEngine → AsyncSessionFactory                         │
│  3. 所有 Repository (注入 session_factory)                        │
│  4. TokenEncryptor (注入 encryption_key)                         │
│  5. 所有 Service (注入所需 Repository + 其他 Service)              │
│  6. BotRegistry (注入 sub_dp, bot_repo, token_encryptor)         │
│  7. Master Bot Handlers (注入所需 Service + BotRegistry)          │
│  8. Sub Bot Handlers (注入 ForwarderService)                     │
└─────────────────────────────────────────────────────────────────┘

Master Handlers 依赖:
  start.py        → (无Service依赖)
  register.py     → TokenValidatorService, BotRepo, BotRegistry
  manage.py       → BotRepo, UserRepo, BotRegistry
  broadcast.py    → BroadcastService, BotRepo
  block.py        → UserRepo, BotRepo
  admin.py        → BotRepo, UserRepo, AdRepo, BroadcastRepo
  ad.py           → AdInjectorService, AdRepo, BotRepo
  callbacks.py    → (路由到上述各 handler)

Sub Bot Handlers 依赖:
  start.py        → UserRepo, BotRepo
  user_message.py → ForwarderService
  owner_reply.py  → ForwarderService

Service 依赖:
  ForwarderService      → UserRepo, MessageMapRepo, BotRepo, AdInjectorService
  BroadcastService      → BroadcastRepo, UserRepo, BotRegistry
  AdInjectorService     → AdRepo
  TokenValidatorService → BotRepo, TokenEncryptor
```

## 2. 数据传输对象（DTO）

Handler 和 Service 之间通过 dataclass 传递数据，不直接传递 ORM 模型。

```python
from dataclasses import dataclass
from datetime import datetime


@dataclass(frozen=True)
class BotInfo:
    """Token验证后返回的Bot信息"""
    bot_id: int
    username: str
    first_name: str


@dataclass(frozen=True)
class SubBotDTO:
    """子Bot信息（传递给Handler层）"""
    id: int
    bot_id: int
    bot_username: str
    owner_id: int
    owner_username: str | None
    status: str
    welcome_message: str | None
    user_count: int
    message_count: int
    created_at: datetime


@dataclass(frozen=True)
class BotUserDTO:
    """终端用户信息"""
    id: int
    sub_bot_id: int
    user_id: int
    username: str | None
    display_name: str
    is_blocked: bool
    is_banned_by_telegram: bool
    first_seen: datetime
    last_active: datetime


@dataclass(frozen=True)
class AdDTO:
    """广告信息"""
    id: int
    name: str
    ad_text: str
    ad_url: str | None
    button_text: str | None
    button_url: str | None
    is_active: bool
    target_type: str
    target_bot_id: int | None
    priority: int
    impression_count: int


@dataclass(frozen=True)
class BroadcastTaskDTO:
    """广播任务信息"""
    id: int
    sub_bot_id: int
    content_type: str
    total_count: int
    sent_count: int
    failed_count: int
    status: str
    created_at: datetime
    completed_at: datetime | None


@dataclass(frozen=True)
class AdInjectionResult:
    """广告注入结果"""
    text: str
    keyboard: "InlineKeyboardMarkup | None"


@dataclass(frozen=True)
class ForwardResult:
    """转发结果"""
    success: bool
    forwarded_msg_id: int | None
    error: str | None


@dataclass(frozen=True)
class BroadcastProgress:
    """广播进度"""
    task_id: int
    total: int
    sent: int
    failed: int
    status: str
    percent: int
    progress_bar: str


@dataclass(frozen=True)
class PaginatedResult:
    """分页结果"""
    items: list
    total: int
    page: int
    page_size: int
    total_pages: int
    has_next: bool
    has_prev: bool
```

## 3. Repository 层接口

所有 Repository 共享同一个 `AsyncSessionFactory`，每次操作创建新的 session。

### 3.1 BaseRepository

```python
class BaseRepository:
    """Repository 基类"""

    def __init__(self, session_factory: async_sessionmaker[AsyncSession]):
        self._session_factory = session_factory
```

### 4.1 TokenValidatorService

```python
class TokenValidatorService:
    """Token 验证与加密服务"""

    def __init__(self, bot_repo: BotRepo, encryptor: TokenEncryptor):
        self._bot_repo = bot_repo
        self._encryptor = encryptor

    def validate_format(self, token: str) -> bool:
        """校验Token格式
        规则: ^\d{8,10}:[A-Za-z0-9_-]{35}$
        """

    async def validate_api(self, token: str) -> BotInfo | None:
        """调用 Telegram API 验证Token
        成功返回 BotInfo(bot_id, username, first_name)
        失败返回 None
        内部: 创建临时 Bot(token) 调用 get_me()，完成后关闭 session
        """

    async def check_duplicate(self, bot_id: int) -> bool:
        """检查 bot_id 是否已注册
        返回: True=已存在, False=未注册
        """

    def encrypt_token(self, token: str) -> str:
        """加密Token用于存储"""

    def decrypt_token(self, encrypted: str) -> str:
        """解密Token用于创建Bot实例"""
```

**依赖：** `BotRepo`, `TokenEncryptor`
**被谁调用：** Master register handler

### 4.2 ForwarderService

```python
class ForwarderService:
    """双向消息转发核心服务"""

    def __init__(
        self,
        user_repo: UserRepo,
        msg_map_repo: MessageMapRepo,
        bot_repo: BotRepo,
        ad_injector: AdInjectorService,
    ):
        self._user_repo = user_repo
        self._msg_map_repo = msg_map_repo
        self._bot_repo = bot_repo
        self._ad_injector = ad_injector

    async def forward_to_owner(
        self,
        bot: Bot,
        sub_bot: SubBotDTO,
        message: Message,
    ) -> ForwardResult:
        """将终端用户的消息转发给Bot主人

        完整流程:
        1. get_or_create 用户记录
        2. 检查封禁状态 → 封禁则回复用户并返回
        3. 构建用户信息头
        4. 根据消息类型选择转发方式
        5. 记录消息映射
        6. 递增消息计数

        参数:
            bot: 子Bot的 aiogram.Bot 实例
            sub_bot: 子Bot数据库记录
            message: 终端用户发送的原始消息

        返回:
            ForwardResult(success, forwarded_msg_id, error)
        """

    async def reply_to_user(
        self,
        bot: Bot,
        sub_bot: SubBotDTO,
        message: Message,
    ) -> ForwardResult:
        """将Bot主人的回复发送给终端用户

        完整流程:
        1. 检查 message.reply_to_message 是否存在
        2. 查找消息映射 → 获取 target_user_id
        3. 调用 AdInjectorService.inject() 注入广告
        4. 根据消息类型发送给终端用户
        5. 记录反向消息映射
        6. 递增消息计数
        7. 发送确认给Bot主人

        参数:
            bot: 子Bot的 aiogram.Bot 实例
            sub_bot: 子Bot数据库记录
            message: Bot主人发送的回复消息

        返回:
            ForwardResult(success, forwarded_msg_id, error)
        """

    async def handle_no_reply(
        self,
        bot: Bot,
        sub_bot: SubBotDTO,
        message: Message,
    ) -> None:
        """Bot主人直接发消息（未回复任何消息）时的处理
        回复提示: "请回复一条转发的消息来回复用户"
        """

    def _build_user_header(self, user: BotUserDTO) -> str:
        """构建用户信息头
        格式: "👤 显示名 (@username) [ID:123456]"
        """
```

**依赖：** `UserRepo`, `MessageMapRepo`, `BotRepo`, `AdInjectorService`
**被谁调用：** Sub Bot user_message handler, Sub Bot owner_reply handler

class AdInjectorService:

        返回:
            AdInjectionResult(text, keyboard)

        """获取某Bot当前应展示的广告（供外部查询用）"""

### 4.4 BroadcastService

```python
class BroadcastService:
    """广播服务"""

    def __init__(
        self,
        broadcast_repo: BroadcastRepo,
        user_repo: UserRepo,
        bot_registry: "BotRegistry",
    ):
        self._broadcast_repo = broadcast_repo
        self._user_repo = user_repo
        self._registry = bot_registry
        self._running_tasks: dict[int, asyncio.Task] = {}  # task_id → asyncio.Task

    async def start(
        self,
        sub_bot_id: int,
        owner_id: int,
        content_type: str,
        content_text: str | None,
        content_file_id: str | None,
        content_caption: str | None,
    ) -> BroadcastTaskDTO:
        """发起广播

        前置检查:
        1. 该Bot是否有正在运行的广播 → 有则抛出 BroadcastError
        2. 距上次广播是否超过5分钟 → 未超过则抛出 BroadcastError
        3. 获取活跃用户列表

        执行:
        1. 创建 BroadcastTask 记录
        2. 启动 asyncio.Task 执行广播
        3. 存入 _running_tasks

        返回: BroadcastTaskDTO

        异常: BroadcastError
        """

    async def cancel(self, task_id: int) -> bool:
        """取消广播

        1. 更新数据库 status='cancelled'
        2. 取消 asyncio.Task
        3. 从 _running_tasks 移除

        返回: True=成功取消, False=任务不存在或已完成
        """

    async def get_progress(self, task_id: int) -> BroadcastProgress | None:
        """查询广播进度

        返回: BroadcastProgress(task_id, total, sent, failed, status, percent, progress_bar)
        """
```

**依赖：** `BroadcastRepo`, `UserRepo`, `BotRegistry`
**被谁调用：** Master broadcast handler

## 5. BotRegistry 接口

```python
class BotRegistry:
    """子Bot生命周期管理器"""

    def __init__(
        self,
        sub_dp: Dispatcher,
        bot_repo: BotRepo,
        encryptor: TokenEncryptor,
    ):
        self._dp = sub_dp
        self._bot_repo = bot_repo
        self._encryptor = encryptor
        self._bots: dict[int, Bot] = {}          # bot_id → Bot实例
        self._polling_task: asyncio.Task | None = None

    async def add_bot(self, token: str, bot_id: int) -> None:
        """添加并启动一个子Bot

        1. 创建 Bot(token) 实例
        2. 存入 _bots[bot_id]
        3. 重启 polling

        异常: 如果Bot创建或polling失败，抛出 RegistryError
        """

    async def remove_bot(self, bot_id: int) -> None:
        """停止并移除一个子Bot

        1. 从 _bots 移除
        2. 关闭 Bot session
        3. 重启 polling（如果还有其他Bot）
        """

    def get_bot(self, bot_id: int) -> Bot | None:
        """获取Bot实例（BroadcastService发送消息用）"""

    def get_all_bot_ids(self) -> list[int]:
        """获取所有运行中的Bot ID列表"""

    def is_running(self, bot_id: int) -> bool:
        """检查某Bot是否正在运行"""

    def count_running(self) -> int:
        """获取运行中的Bot数量"""

    async def recover_all(self) -> dict[str, int]:
        """启动时恢复所有活跃Bot

        1. 查询数据库所有 status='active' 的Bot
        2. 逐个解密Token
        3. 逐个创建Bot实例并验证（get_me）
        4. 验证失败 → 标记 status='error'
        5. 验证成功 → 加入 _bots
        6. 启动 polling

        返回: {"recovered": 成功数, "failed": 失败数}
        """

    async def restart_polling(self) -> None:
        """重启 polling（内部方法，add/remove后调用）

        1. 取消当前 _polling_task
        2. 如果 _bots 非空，创建新的 polling task
        """

    async def shutdown(self) -> None:
        """关闭所有Bot（程序退出时调用）

        1. 取消 _polling_task
        2. 关闭所有 Bot session
        3. 清空 _bots
        """
```

**依赖：** `Dispatcher`(sub_dp), `BotRepo`, `TokenEncryptor`
**被谁调用：**
| 调用方 | 调用的方法 |
|--------|-----------|
| Master register handler | `add_bot` |
| Master manage handler | `remove_bot`, `add_bot`(重启), `is_running` |
| Master admin handler | `remove_bot`(强制停止), `count_running` |
| BroadcastService | `get_bot` |
| Launcher | `recover_all`, `shutdown` |

## 7. Handler 层接口约定

Handler 不对外暴露接口，但需遵守以下约定：

### 7.1 Handler 函数签名规范

```python
# Master Bot Handler 签名
async def handler_name(
    message: Message,                    # 或 CallbackQuery
    state: FSMContext,                   # FSM 状态（需要时）
    # 以下通过 Dispatcher 的 workflow_data 注入:
    bot_repo: BotRepo,                  # 需要时
    user_repo: UserRepo,                # 需要时
    forwarder: ForwarderService,        # 需要时
    broadcast_svc: BroadcastService,    # 需要时
    ad_injector: AdInjectorService,     # 需要时
    token_validator: TokenValidatorService,  # 需要时
    registry: BotRegistry,              # 需要时
) -> None:
    ...

# Sub Bot Handler 签名
async def handler_name(
    message: Message,
    bot: Bot,                           # aiogram 自动注入
    sub_bot: SubBotDTO,                 # BotContextMiddleware 注入
    forwarder: ForwarderService,        # workflow_data 注入
) -> None:
    ...
```

### 7.2 依赖注入方式

通过 Dispatcher 的 `workflow_data` 在启动时注入：

```python
# launcher.py 中
master_dp.workflow_data.update({
    "bot_repo": bot_repo,
    "user_repo": user_repo,
    "msg_map_repo": msg_map_repo,
    "ad_repo": ad_repo,
    "broadcast_repo": broadcast_repo,
    "forwarder": forwarder_service,
    "broadcast_svc": broadcast_service,
    "ad_injector": ad_injector_service,
    "token_validator": token_validator_service,
    "registry": bot_registry,
    "settings": settings,
})

sub_dp.workflow_data.update({
    "forwarder": forwarder_service,
    "user_repo": user_repo,
    "bot_repo": bot_repo,
})
```

aiogram 会自动将 `workflow_data` 中的值按参数名匹配注入到 handler 函数中。

## 8. 异常定义

```python
class BiBotError(Exception):
    """基础异常"""
    pass

class TokenValidationError(BiBotError):
    """Token验证失败"""
    pass

class TokenFormatError(TokenValidationError):
    """Token格式错误"""
    pass

class TokenInvalidError(TokenValidationError):
    """Token无效（API验证失败）"""
    pass

class TokenDuplicateError(TokenValidationError):
    """Token已被注册"""
    pass

class TokenLimitError(TokenValidationError):
    """超出注册数量限制"""
    pass

class RegistryError(BiBotError):
    """BotRegistry操作失败"""
    pass

class BroadcastError(BiBotError):
    """广播操作失败"""
    pass

class ForwardError(BiBotError):
    """转发操作失败"""
    pass
```

**异常处理规则：**
| 层 | 抛出异常 | 捕获异常 |
|----|---------|---------|
| Repository | SQLAlchemy 异常（不捕获，向上传播） | - |
| Service | 自定义业务异常 | SQLAlchemy 异常 → 转为业务异常 |
| Handler | - | 业务异常 → 转为用户友好的消息回复 |

```python
# Handler 中的异常处理示例
async def register_confirm(callback: CallbackQuery, token_validator, registry, ...):
    try:
        bot_info = await token_validator.validate_api(token)
        await registry.add_bot(token, bot_info.bot_id)
        await callback.message.edit_text("注册成功!")
    except TokenInvalidError:
        await callback.message.edit_text("Token无效，请重新注册")
    except TokenDuplicateError:
        await callback.message.edit_text("该Bot已被注册")
    except RegistryError as e:
        await callback.message.edit_text(f"Bot启动失败: {e}")
```
