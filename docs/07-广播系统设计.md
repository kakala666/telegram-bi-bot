# 07 - 广播系统设计

## 1. 广播系统概述

Bot主人可以通过主Bot向自己子Bot的所有终端用户群发消息。
支持文字、图片、视频、文件、音频等多种消息类型。

### 步骤5：广播执行过程

```python
async def execute_broadcast(task: BroadcastTask, users: list[BotUser]):
    """异步执行广播"""
    bot = registry.get_bot(task.sub_bot_id)
    rate_limit = settings.BROADCAST_RATE_LIMIT  # 默认20条/秒
    delay = 1.0 / rate_limit  # 每条消息间隔

    for user in users:
        if task.status == 'cancelled':
            break

        try:
            await send_broadcast_message(bot, user.user_id, task)
            task.sent_count += 1

        except TelegramForbiddenError:
            # 用户已屏蔽Bot
            task.failed_count += 1
            user.is_banned_by_telegram = True
            await user_repo.update(user)

        except TelegramRetryAfter as e:
            # Telegram要求等待（触发限速）
            await asyncio.sleep(e.retry_after)
            # 重试当前用户
            try:
                await send_broadcast_message(bot, user.user_id, task)
                task.sent_count += 1
            except Exception:
                task.failed_count += 1

        except Exception:
            task.failed_count += 1

        # 限速等待
        await asyncio.sleep(delay)

        # 每50条更新一次数据库进度
        if (task.sent_count + task.failed_count) % 50 == 0:
            await broadcast_repo.update_progress(task)

    # 广播完成
    task.status = 'completed'
    task.completed_at = datetime.utcnow()
    await broadcast_repo.update(task)
```

## 4. 广播消息发送逻辑

```python
async def send_broadcast_message(
    bot: Bot, user_id: int, task: BroadcastTask
):
    """根据内容类型发送广播消息"""

    match task.content_type:
        case "text":
            await bot.send_message(
                chat_id=user_id,
                text=task.content_text,
                parse_mode="HTML"
            )

        case "photo":
            await bot.send_photo(
                chat_id=user_id,
                photo=task.content_file_id,
                caption=task.content_caption,
                parse_mode="HTML"
            )

        case "video":
            await bot.send_video(
                chat_id=user_id,
                video=task.content_file_id,
                caption=task.content_caption,
                parse_mode="HTML"
            )

        case "document":
            await bot.send_document(
                chat_id=user_id,
                document=task.content_file_id,
                caption=task.content_caption,
                parse_mode="HTML"
            )

        case "audio":
            await bot.send_audio(
                chat_id=user_id,
                audio=task.content_file_id,
                caption=task.content_caption,
                parse_mode="HTML"
            )

        case "sticker":
            await bot.send_sticker(
                chat_id=user_id,
                sticker=task.content_file_id
            )
```

## 5. 限速策略

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `BROADCAST_RATE_LIMIT` | 20 | 每秒最大发送消息数 |
| 每条间隔 | 50ms (1/20) | 两条消息之间的等待时间 |
| 批量更新 | 每50条 | 每发送50条更新一次数据库进度 |

### Telegram API 限制参考

- 同一用户: 1条/秒
- 同一群组: 20条/分钟
- 批量发送: ~30条/秒（超过会收到 429 RetryAfter）
- 建议设置: 20条/秒，留有余量

### RetryAfter 处理

```
收到 TelegramRetryAfter 异常:
├─→ 读取 e.retry_after（Telegram要求等待的秒数）
├─→ asyncio.sleep(retry_after)
├─→ 重试发送
└─→ 如果仍然失败，记为 failed
```

## 6. 广播限制规则

| 规则 | 说明 |
|------|------|
| 同时只能有1个广播 | 同一子Bot同时只能运行一个广播任务 |
| 最小间隔 | 两次广播之间至少间隔5分钟 |
| 内容限制 | 文本最长4096字符，caption最长1024字符 |

### 并发检查

```python
async def start_broadcast(sub_bot_id: int, ...):
    # 检查是否有正在运行的广播
    running = await broadcast_repo.get_running(sub_bot_id)
    if running:
        raise BroadcastError("该Bot已有正在进行的广播任务，请等待完成后再试")

    # 检查最小间隔
    last = await broadcast_repo.get_latest(sub_bot_id)
    if last and (now - last.created_at).seconds < 300:
        raise BroadcastError("两次广播之间请至少间隔5分钟")
```

## 7. 进度条生成

```python
def generate_progress_bar(current: int, total: int, length: int = 20) -> str:
    """生成文本进度条"""
    if total == 0:
        return "░" * length + " 0%"

    percent = current / total
    filled = int(length * percent)
    bar = "█" * filled + "░" * (length - filled)
    return f"{bar} {int(percent * 100)}%"

# 示例输出:
# ██████████████░░░░░░ 72%
# ████████████████████ 100%
```
