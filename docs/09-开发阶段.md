# 09 - 开发阶段

## 总览

项目分为 6 个阶段，每个阶段有明确的交付物和验收标准。

```
Phase 1: 基础骨架        → 项目能启动，数据库能连接
Phase 2: 主机器人        → 主Bot能响应命令，能注册Token
Phase 3: 子Bot运行时     → 双向消息转发正常工作
Phase 4: 广告注入        → 回复消息带广告小尾巴
Phase 5: 广播功能        → 群发消息正常工作
Phase 6: 管理与优化      → 管理面板、错误恢复、日志
```

```
4. 提交无效Token → 提示错误
5. 提交重复Token → 提示已注册
6. 发送 /mybot → 显示Bot列表
7. 点击管理按钮 → 显示管理面板
8. 停止/重启/删除操作正常执行
9. 设置欢迎语正常保存
10. 用户列表分页正常
```

### 验收标准

```
1. 注册Bot后，子Bot自动开始工作
2. 终端用户给子Bot发 /start → 收到欢迎语
3. 终端用户发文本消息 → Bot主人收到（带用户信息头）
4. 终端用户发图片/视频/文件 → Bot主人收到
5. Bot主人回复消息 → 终端用户收到回复
6. Bot主人直接发消息（不回复）→ 收到提示
7. 多用户同时发消息 → 回复路由正确
8. 重启程序 → 所有active子Bot自动恢复
9. 被封禁用户发消息 → 收到封禁提示
```

| 4.5 | 实现编辑/删除/启停广告 | `app/master_bot/handlers/ad.py` |
| 4.6 | 实现全局广告 vs 指定Bot广告 | `app/services/ad_injector.py` |
| 4.7 | 实现广告展示计数 | `app/repositories/ad_repo.py` |
| 4.8 | 创建默认广告（首次启动时） | `app/launcher.py` |

### 验收标准

```
1. Bot主人回复文本 → 终端用户收到带广告尾巴的消息
2. Bot主人回复图片 → caption末尾有广告
3. Bot主人回复贴纸 → 贴纸后跟一条广告消息
4. /ad 显示广告列表
5. 添加新广告 → 流程完整，数据库写入
6. 停用广告 → 不再展示
7. 指定Bot广告优先于全局广告
8. 广告展示计数正确递增
9. 无活跃广告时 → 不注入任何内容
```

```bash
pip install aiogram sqlalchemy[asyncio] aiosqlite alembic pydantic-settings cryptography
```
