# 06 - 广告系统设计

## 1. 广告系统概述

广告系统是平台的变现手段。当子Bot将Bot主人的回复发送给终端用户时，在消息末尾自动附加广告文本（小尾巴）。

### 广告展示位置

```
仅在此方向注入广告:
Bot主人回复 → 子Bot → 终端用户
                ↑
           广告注入点

不注入广告的方向:
终端用户 → 子Bot → Bot主人（无广告）
```

### 广告展示效果

**文本消息：**
```
你好，感谢你的咨询，我们的营业时间是...

━━━━━━━━━━━━━━━
📢 Powered by @PlatformBot | 创建你的双向机器人
```

**带按钮的广告：**
```
你好，感谢你的咨询...

━━━━━━━━━━━━━━━
📢 Powered by @PlatformBot
[👉 免费创建你的Bot]  ← 内联按钮，点击跳转
```

**媒体消息（有caption）：**
```
[图片/视频]
原始caption内容...

━━━━━━━━━━━━━━━
📢 Powered by @PlatformBot
```

**媒体消息（无caption，如贴纸/语音）：**
```
[贴纸/语音消息]

（单独一条消息）
━━━━━━━━━━━━━━━
📢 Powered by @PlatformBot
```

## 2. 广告类型

| 类型 | 说明 | 展示方式 |
|------|------|----------|
| **全局广告** | 所有子Bot统一展示 | target_type = 'global' |
| **指定Bot广告** | 仅特定子Bot展示 | target_type = 'specific', target_bot_id = N |

### 广告优先级规则

```
选择广告的逻辑:
1. 查找该 sub_bot_id 的专属广告（target_type='specific'）
   └─→ 有活跃的专属广告 → 使用专属广告（按 priority DESC 取最高）
2. 没有专属广告 → 使用全局广告（target_type='global'）
   └─→ 有活跃的全局广告 → 按 priority DESC 取最高
3. 没有任何活跃广告 → 不注入广告
```

## 3. AdInjectorService 详细逻辑

### inject() 方法

```python
async def inject(self, text: str | None, sub_bot_id: int) -> tuple[str, InlineKeyboardMarkup | None]:
    """
    注入广告到文本中。

    参数:
        text: 原始文本（可能为None，如纯媒体消息）
        sub_bot_id: 子Bot ID

    返回:
        (注入广告后的文本, 广告按钮keyboard或None)
    """
    ad = await self._get_active_ad(sub_bot_id)

    if not ad:
        return (text or "", None)

    # 更新展示计数
    await self._ad_repo.increment_impression(ad.id)

    # 构建广告文本
    separator = "\n\n━━━━━━━━━━━━━━━"
    ad_line = f"{separator}\n{ad.ad_text}"

    if ad.ad_url and not ad.button_text:
        # URL直接附在文本中
        ad_line += f"\n{ad.ad_url}"

    # 构建广告按钮（如果有）
    ad_keyboard = None
    if ad.button_text and ad.button_url:
        ad_keyboard = InlineKeyboardMarkup(inline_keyboard=[
            [InlineKeyboardButton(text=ad.button_text, url=ad.button_url)]
        ])

    if text:
        return (f"{text}{ad_line}", ad_keyboard)
    else:
        return (ad_line.lstrip("\n"), ad_keyboard)
```

### 不同消息类型的注入策略

```python
async def send_reply_with_ad(
    self, bot: Bot, sub_bot: SubBot,
    target_user_id: int, message: Message
):
    """将Bot主人的回复发送给终端用户，并注入广告"""

    ad_text, ad_keyboard = await self.ad_injector.inject(None, sub_bot.id)

    if message.text:
        # ===== 文本消息 =====
        full_text, ad_kb = await self.ad_injector.inject(
            message.text, sub_bot.id
        )
        return await bot.send_message(
            chat_id=target_user_id,
            text=full_text,
            reply_markup=ad_kb,
            parse_mode="HTML"
        )

    elif message.photo:
        # ===== 图片消息 =====
        caption = message.caption or ""
        full_caption, ad_kb = await self.ad_injector.inject(
            caption, sub_bot.id
        )
        # caption 最大1024字符，超出则截断广告
        if len(full_caption) > 1024:
            full_caption = full_caption[:1024]
        return await bot.send_photo(
            chat_id=target_user_id,
            photo=message.photo[-1].file_id,
            caption=full_caption,
            reply_markup=ad_kb,
            parse_mode="HTML"
        )

    elif message.video:
        # ===== 视频消息 =====
        caption = message.caption or ""
        full_caption, ad_kb = await self.ad_injector.inject(
            caption, sub_bot.id
        )
        if len(full_caption) > 1024:
            full_caption = full_caption[:1024]
        return await bot.send_video(
            chat_id=target_user_id,
            video=message.video.file_id,
            caption=full_caption,
            reply_markup=ad_kb,
            parse_mode="HTML"
        )

    elif message.document:
        # ===== 文件消息 =====
        caption = message.caption or ""
        full_caption, ad_kb = await self.ad_injector.inject(
            caption, sub_bot.id
        )
        if len(full_caption) > 1024:
            full_caption = full_caption[:1024]
        return await bot.send_document(
            chat_id=target_user_id,
            document=message.document.file_id,
            caption=full_caption,
            reply_markup=ad_kb,
            parse_mode="HTML"
        )

    elif message.sticker:
        # ===== 贴纸 =====
        # 贴纸不支持caption，先发贴纸再发广告
        await bot.send_sticker(
            chat_id=target_user_id,
            sticker=message.sticker.file_id
        )
        if ad_text:
            return await bot.send_message(
                chat_id=target_user_id,
                text=ad_text,
                reply_markup=ad_keyboard,
                parse_mode="HTML"
            )

    elif message.voice:
        # ===== 语音 =====
        await bot.send_voice(
            chat_id=target_user_id,
            voice=message.voice.file_id
        )
        if ad_text:
            return await bot.send_message(
                chat_id=target_user_id,
                text=ad_text,
                reply_markup=ad_keyboard,
                parse_mode="HTML"
            )

    else:
        # ===== 其他类型: 降级为 copy_message =====
        await bot.copy_message(
            chat_id=target_user_id,
            from_chat_id=message.chat.id,
            message_id=message.message_id
        )
        if ad_text:
            return await bot.send_message(
                chat_id=target_user_id,
                text=ad_text,
                reply_markup=ad_keyboard,
                parse_mode="HTML"
            )
```

| 指标 | 说明 |

| 点击率 | 需要 Telegram 内联按钮回调统计（扩展功能） |
